Antarmuka Pengguna 5. Mode Analisis Kapasitas 6. Mode Pencarian Duplikat 7. Interaksi & Navigasi 8. FAQ & Troubleshooting 9. Tips & Praktik Terbaik 1. Pendahuluan FolderAnalyzer adalah aplikasi desktop ringan berbasis Python yang dirancang untuk membantu Anda: 📊 Menganalisis penggunaan ruang penyimpanan folder secara hierarkis. 🔍 Menemukan file duplikat berdasarkan hash MD5 (akurat & cepat). 🗑️ Menghapus file/folder duplikat atau tidak terpakai secara aman. Berjalan tanpa instalasi Python (portable .exe). Aplikasi ini tidak mengubah, memindahkan, atau mengunggah data Anda. Semua proses berjalan lokal di komputer Anda. 2. Persyaratan Sistem Komponen Spesifikasi Minimum Sistem Operasi Windows 10 / 11 (64-bit) RAM 2 GB tersedia Penyimpanan ~15 MB untuk file aplikasi Dependensi Visual C++ Redistributable (biasanya sudah terinstal) ️ Aplikasi ini tidak memerlukan Python terinstal di komputer target. Cukup extract folder dist/FolderAnalyzer/ dan jalankan. 3. Instalasi & Menjalankan Ekstrak folder FolderAnalyzer.zip (atau copy folder dist/FolderAnalyzer/ hasil build). Buka folder tersebut, lalu double-click FolderAnalyzer.exe. Jika muncul peringatan Windows SmartScreen, klik Info selengkapnya → Jalankan saja. Aplikasi akan terbuka dalam beberapa detik. Tidak ada proses instalasi. 💡 Untuk akses penuh ke folder sistem (misal: C:\Windows atau Program Files, jalankan FolderAnalyzer.exe sebagai Administrator (klik kanan → Run as administrator). 4. Antarmuka Pengguna Elemen Fungsi ⚙️ Mode Operasi Pilih antara Analisis Kapasitas atau Cari Duplikat (MD5) 📂 Path Folder Input lokasi folder yang akan dianalisis (bisa diketik atau klik Cari) ▶️ Mulai / ⛔ Hentikan Mulai proses analisis atau batalkan secara aman Progress Bar Menunjukkan persentase kemajuan pemrosesan file 📑 Tab Notebook Memisahkan tampilan hasil kapasitas & duplikat 🗑️ Hapus Duplikat Aktif hanya di mode duplikat untuk menghapus file terpilih 5. Mode Analisis Kapasitas Mode ini menampilkan struktur folder dalam bentuk pohon hierarkis lengkap dengan ukuran akumulatif. Cara Menggunakan: Pilih Analisis Kapasitas. Masukkan path folder → klik Mulai Analisis. Tunggu progress selesai. Hasil akan muncul di tab Pohon Folder & Ukuran. Klik ikon ▶/▼ atau Double-Click pada folder untuk expand/collapse. Klik header kolom (Nama, Tipe, Ukuran, Path) untuk mengurutkan data. Ukuran folder dihitung secara rekursif (menjumlahkan semua file & subfolder di dalamnya). 6. Mode Pencarian Duplikat Mode ini mencari file dengan konten identik menggunakan algoritma hash MD5. Proses dioptimalkan dengan filter ukuran file terlebih dahulu. Cara Menggunakan: Pilih 🔍 Cari Duplikat (MD5). Masukkan path folder → klik Mulai Analisis. Hasil muncul di tab File Duplikat dalam bentuk grup berdasarkan hash. Klik baris grup → tombol 🗑️ Hapus Duplikat akan aktif. Konfirmasi penghapusan. File pertama dalam grup akan dihapus permanen. ⚠️ Penghapusan bersifat permanen (tidak masuk Recycle Bin). Pastikan file yang dihapus benar-benar salinan. 7. Interaksi & Navigasi Aksi Hasil Double-Click pada Folder Expand / Collapse isi folder Double-Click pada File Buka file dengan aplikasi default sistem Klik Kanan pada Item Buka menu konteks: Expand/Collapse atau Hapus Klik Header Kolom Urutkan data Ascending / Descending Ctrl+S (di VSCode) Pastikan kode tersimpan sebelum rebuild .exe 8. FAQ & Troubleshooting ❓ Aplikasi tidak terbuka / muncul error DLL Pastikan Anda mendistribusikan seluruh folder dist/FolderAnalyzer/, bukan hanya file .exe-nya. Folder _internal/ wajib ikut karena berisi dependensi Python & Tkinter. ❓ Progress bar berhenti di 0% atau 99% Ini normal jika folder berisi banyak file kecil atau ada symlink. Aplikasi tetap berjalan di background. Gunakan tombol ⛔ Hentikan jika ingin membatalkan. ❓ Muncul Permission Denied saat hapus/scan Jalankan aplikasi sebagai Administrator atau pastikan tidak ada program lain yang mengunci file tersebut (misal: antivirus, explorer, atau editor). ❓ Hasil duplikat terlihat salah Algoritma hanya mencocokkan file dengan ukuran byte identik terlebih dahulu, lalu menghitung MD5. Jika ukuran sama tapi konten berbeda, tidak akan terdeteksi sebagai duplikat (akurat). 9. Tips & Praktik Terbaik 🔒 Backup dulu: Sebelum menghapus duplikat massal, salin folder penting ke drive eksternal. 📁 Scan bertahap: Untuk drive besar, analisis per folder utama (misal: D:\Dokumen, lalu D:\Foto) agar lebih cepat. 🔄 Rebuild aplikasi: Jika Anda mengembangkan fitur baru, jalankan perintah build di terminal VSCode: Remove-Item -Recurse -Force build, dist, *.spec -ErrorAction SilentlyContinue; .\build_env\Scripts\pyinstaller.exe --onedir --windowed --name "FolderAnalyzer" --collect-all tkinter chech-folder.py 📦 Distribusi: Kompres folder dist/FolderAnalyzer/ menjadi .zip sebelum dibagikan.
